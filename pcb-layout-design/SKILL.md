# PCB 布局与走线

本技能负责电气、机械、制造约束下的设计取舍与验收。以当前工程、器件资料和原生检查为依据；不把工具调用成功或器件全部有坐标视为设计完成。

## 1. 明确范围和输入

| 任务 | 实际完成范围 |
|---|---|
| 仅布局 | 器件位置、关键局部电路、装配空间和通道可行性；不增加走线、铺铜或制造导出任务 |
| 全板设计 | 布局、走线、填铜及最终验证；制造文件按请求生成 |
| 局部优化 | 指定对象及必要关联区域，检查修改影响 |
| 审查 | 读取工程，输出有位置和证据的发现，不自动改板 |
| 投板准备 | 对应版本检查及所需制造/装配文件，外部上传下单沿用明确授权 |

先读工程根目录的 `PCB需求.md`（如有）、原理图注释、机械与制造资料。模板见 [assets/PCB需求.md](assets/PCB需求.md)：用户需要时复制到工程，不覆盖已有文件，不要求重复填写已知输入。只有影响设计选择、正确性或交付可用性的缺项才询问，普通可逆选择自行推进。

区分从原理图新建、整体重设计与局部修改。新建依据电路关系独立布局；重设计按授权重新规划；局部修改保留无关区域。报告实际沿用范围，不将恢复旧坐标称为独立布局。

## 2. 不可用优化指标抵消的约束

- 保持电路、引脚映射、极性及已确认结构要求；变更须在授权范围内从相应设计源同步。
- 器件本体、安装高度、通孔及焊脚、插拔维修包络与铜间距分别检查。不能为放下更多器件而忽略本体、假设可叠放或缩减有效间距。
- 电源供回、去耦、反馈、时钟、敏感模拟、接口保护和天线按实际功能与器件要求处理。物理邻近或同网连通不能替代环路与参考检查。
- 不通过关闭检查、放宽有效规则或任意排除对象获得合格结果。候选中的未安排对象必须明确，不得静默沿用旧位置后宣称完成。
- 默认禁止自动走线及自动寻路器。可批量写入明确规划的路径；自动布局或摆放搜索也必须保留全部适用硬约束，其结果只是候选。

硬约束满足后，再比较整组可布线性、关键路径、回流、过孔、折弯、装配及整齐程度。不要仅优化器件摆入率、飞线总长、过孔总数、DRC 条数或到预设坐标的距离。

## 3. 两阶段设计流程

新板默认分两阶段执行：第一阶段完成设计准备与布局，交付后等待硬件工程师或用户指定审核人确认，再进入第二阶段布线、铺铜与验证。用户明确要求连续完成全板时按该授权执行，不增加重复确认。已有针对当前布局版本的确认继续有效；不能把确认其他版本或含糊的“继续”解释为批准改变固定约束。仅布局请求在第一阶段完成后结束。

共用一个原生工程，不创建两套互相漂移的设计。维护工程根目录的简短 `PCB阶段记录.md`：目标工程/板卡及保存版本、当前阶段、功能分组与关键元件作用、固定位置/操作方向/装配要求、关键电路与预留通道、检查结果/未解决项、确认来源及对应版本。可复用已有等价记录，不重复造表；记录由 AI 根据实际工作更新，不要求用户额外填表。

### 第一阶段：设计准备与布局

#### A. 理解工程并建立基线

先说明产品如何使用、功能模块如何连接，以及影响摆件的关键元件作用。重复电路成组说明，不逐个罗列无关参数。识别按钮的实际按压方向、接口插拔、屏幕观看方向及电池/外壳关系；不能按焊盘方便或位号猜测朝向，缺少决定性结构信息时先询问。

识别目标板、原理图、封装、现有规则和修改状态。核对实际引脚映射、装配变体及固定对象。大范围修改保留可恢复版本；登记板框、禁布区、装配轮廓和功能铜区的用途，修改后对照检查。

先读[布局与机械约束](references/layout-and-mechanics.md)及[已有规则检查](references/manufacturing-and-kicad.md#3-设计开始前检查已有规则)。对影响当前布局的叠层和工艺先确认；仅布局时不增加与当前决策无关的叠层参数试验。

#### B. 先验证关键布局，再补普通器件

先确定接口、安装件、模块包络和关键功能块可同时成立，再安排局部电路及普通器件。密集板先检查最受限制的大件、通孔和操作空间；装配关系不明且影响可行性时提前询问。

按实际引脚关系规划模块，预留主控扇出、供回铜、散热和跨模块通道。稳压器同时考虑输入与主负载，去耦检查实际供回环路。满足电气、热、机械和通道要求时优先单面装配，不强行为单面或整齐牺牲关键关系。

搜索候选按布局专题第 5 节执行，保持功能组及引脚关系；硬约束失效的候选不进入优劣评分。既不无限尝试位置排列，也不因搜索失败断言尺寸必然不可行：定位具体冲突，调整可移动对象或提出必要的约束变更选项。

仅布局到此进入布局验收；允许预期未连接存在，不要求布通。关键通道用端点、出口和空间评估，不以实际走线扩大任务。

#### C. 布局验收与交接

完成第 6 节布局验收后，保存原生工程，提供清晰顶底面或适用视图及关键待确认项，在阶段记录中标为“布局已检查，待审核”。存在未解决必修冲突时仍处于布局修复，不得以阶段交接为由收尾。审核通过后记录确认范围和版本；未实际发生的确认不得代填。

### 第二阶段：布线、铺铜与设计验证

开始前读取阶段记录并核对当前工程是否仍对应已确认布局。普通可移动阻容的位置/朝向可在原授权范围内直接优化，复查相关环路、邻线和装配；模块级调整先定位原因并局部重新评估布局，不重启全板。改变已确认按钮方向、接口、板框、安装孔、电路或其他固定约束时，提交具体变更和影响，获得相应确认后更新基线。未受影响的布局确认不失效。

先按[网络功能分组](references/layout-and-mechanics.md#21-网络功能分组)明确端点、优先级、参考及验证方法，再按[通道规划](references/routing-geometry-and-coupling.md#14-工整度检查与局部整理流程)安排整组出口。未识别网络不默认归为普通低速。

共同安排关键路径、电源铜和参考铜；避免单根占道后让其余线路大幅绕远。明显折返、外围绕行、反复换层时检查布局、次序和分层原因。依据实际叠层处理相邻层耦合，不为脚本方便统一塞入某一层。

按[批量编辑与修复闭环](references/edit-and-repair-workflow.md)先验证公共参数和代表性试布，再分组写入、检查新增违规和修复。保留已通过区域，同类错误先查共同根因；超时后先读现场，不能盲目重复创建。

每组完成执行[关键网络检查](references/review-checklists.md#2-关键网络完成或修改后的检查)，修改影响参考或连接时重新填铜复核。全板最终填铜后检查真实铜形状，不只看铜区边界。

### 后续工作：制造输出与样板验证

第二阶段完成表示设计工程及适用检查完成，不表示已获投板批准。制造/装配资料按独立请求生成，由硬件工程师审核；样板功能、供电、温升及适用整机测试单列，不纳入软件检查通过声明，也不自动上传下单。

## 5. 工具执行边界

接入不依赖本技能。使用嘉立创客户端命令行时按当前[官方 AI CLI 指南](https://prodocs.lceda.cn/storage/texts/api/guide/cli-for-ai.md)操作，先执行 `lceda-pro doctor` 并核对目标工程；不另创接入流程或猜测接口。其他 EDA 使用其官方支持且保留对象语义的接口。

调用状态、业务结果、保存结果和实际状态分别核对，`ok=true` 不替代业务成功；对关键设置回读，持久性存疑时保存重开。工具创建图元不代表自动避障。不得以未经验证的文本改写替代复杂原生几何编辑。权限问题按实际执行环境处理，不绕过限制。

原生 DRC、连接检查、几何筛查和装配检查各有边界；不能互相冒充。检查方法失效时说明不能证明的结论，不扩大能力声明。原生备份避免在活动工程中造成同 UUID 文档冲突。

## 6. 验收与持续执行

| 范围 | 完成条件 |
|---|---|
| 布局 | 完整装配方案覆盖全部对象；本体、孔、铜及结构无未解决必修冲突；关键局部电路和通道有依据；预期未连接单列 |
| 局部修改 | 请求内容完成，相关网络、邻域及结构完成适用回归检查 |
| 全板设计 | 走线与最终填铜完成，原生 DRC、未连接及原理图一致性检查有结果，关键供回/参考/装配检查完成，无未解决必修项 |
| 评审 | 发现可定位、有证据，已确认问题与待验证风险分开 |
| 投板准备 | 对应版本通过适用检查，所需制造/装配文件同版本生成并核对 |

问题按“严重度、对象/位置、证据、影响、处理、状态”简要记录。DRC 例外须有具体依据；几何等长不证明阻抗通过，零 DRC 不证明整机性能通过。

检查未通过则定位根因、局部修复并复查。工具可用且有可执行步骤时持续推进；不得把保存成功、阶段预览、器件数量齐全或未完成报告当作停止理由。用户缩小到“仅布局”是缩小范围，不是取消布局验收。

真正依赖用户输入、权限或外部条件时，保存状态、具体阻塞和下一步，继续不受影响的工作；不无限盲试，不为消除报错改变硬约束。按本节约定完成第一阶段后等待审核，是正常阶段交接；阶段内存在可修复的必修问题时不能提前结束。用户要求停止时按要求停止。

交付原生工程、适合审核的视图及简短验证结果，说明实际修改范围、待确认项和路径。制造文件按请求生成；CLI 任务报告本次会话关闭情况并保留用户原有会话。关键检查通过且无新问题后停止重复验证。未做样机、SI/PI、热或整机验证不得声称通过。
