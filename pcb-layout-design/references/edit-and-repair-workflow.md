# 批量编辑与修复闭环

用于通过脚本/API 执行布局、走线和修改。与主技能的电气、机械和制造约束共同使用；本流程不授权自动走线或自动寻路。

## 1. 基础状态先确认

扇出和走线前读取实际物理叠层、层用途、有效线宽/间距、孔径/外径及层对。设置后核对接口业务返回值及状态回读；顶层 `ok=true` 仅证明调用正常返回时，不能替代业务成功。图层已启用或内层能创建图元，也不能证明物理叠层正确。

保存后检查持久性；首次使用叠层设置接口、回读不一致或怀疑缓存时，保存并重新打开核对。不对每个普通对象重复重开。叠层未确认前暂停依赖该叠层的布线，继续连接核对等独立工作。不得为设置成功而直接猜写原生文件记录；不受支持的接口应按主技能的工具能力边界处理。

创建函数的孔径、外径、线宽和层参数来自已核对的有效规则，显式处理单位和参数顺序，不把随手选的常数批量应用于全板。

## 2. 代表性试布后扩大范围

首次采用编辑接口或改变公共参数/写入逻辑时，选择一小组真实网络，覆盖本次会使用的焊盘引出、邻线避让及换层过孔。规划路径后写入、读取几何并执行原生检查，确认参数及行为符合预期，再使用相同方法处理其他网络。没有换层需求时不人为增加过孔做测试。

原始图元创建接口通常不能被假定具有避障或推挤能力。写入前检查走线的实际宽度、焊盘外形、过孔外径与孔、板边和禁布区域，而不是只检查中心线或网名。可用离线几何筛查辅助人工规划，但须注明未覆盖的对象类型，并以原生 DRC 复核；检查脚本不得暗中变成自动寻路器。

## 3. 分组实施与新增问题控制

每批按可检查的网络组或区域组织，保留批前基线、修改/创建对象 ID 和可恢复状态。检查保存与部分失败情况后，执行对应原生连接和间距检查；工具只支持全板检查时，从全板结果定位本批影响。

比较规则类型、对象对、层和位置，合并重复报告用于分析，保留原始明细。报告总数下降不能证明关键问题改善；也不能要求尚未布线的全板未连接数在每批都清零。每批应消除自身新增的非预期冲突及断连，或回退失败方案，再扩大写入范围。

同类问题集中出现时，暂停沿用当前方式批量创建，先查单位、参数、坐标变换、重复对象和通道交叉等共同原因。仅修复或重规划受影响部分，不一边制造同类问题一边逐条补丁。

## 4. 有界返工与恢复

优先修改冲突线段及关联网络，保留已通过区域。扩大到模块布局或层分配调整前，指出现有通道无法满足的具体约束、影响范围及预期收益，不把全板清空作为默认修复方法。结构、电路及已确认输入的变更仍受原授权范围约束。

替换前准备新路径和回退数据；以完整网络组完成替换并检查，避免只删除后续尚无方案的网络。多步接口不具备事务性时记录实际成功的对象，失败后读取现场再恢复或继续。

超时或返回不明确时，不直接重放整批创建。重复对象判断至少考虑网络、层/层对、实际几何和连接用途；同坐标或坐标取整相同不能单独成为删除依据。

连续局部修补没有减少同一根因或导致冲突转移时，重新审视通道/布局方法，而不是无限盲试或直接结束任务。最终仍按主技能完成填铜、原生全板验证和关键电路复核。
